# 👓 VisionCare AI
**AI-Powered Optical Center Customer Service & Triage Agent**

مساعد ذكي تفاعلي مبني بلغة بايثون ومرتبط ببوت تيليجرام لخدمة عملاء مركز بصريات افتراضي (**مركز الرؤية الواضحة للبصريات - تعز**). يعتمد النظام على نموذج **Gemini 3.6 Flash** ويوفر ذاكرة محادثة دائمة عبر **SQLite**، مع دعم أدوات الفحص والحجز والتحويل البشري الفوري التفاعلي عبر مجموعة موظفين وفق قواعد أمان طبية صارمة.

---

## 🌟 الميزات الرئيسية (Key Features)

- 🧠 **AI Agent & Tools (Function Calling):** استخدام تلقائي للأدوات الذكية لتسجيل الحجوزات أو تصعيد المحادثة لموظف بشري دون تدخل يدوي.
- 🔄 **Bi-directional Human Handoff:**
  - تحويل العميل تلقائياً عند طلب موظف أو رصد حالة طارئة.
  - إرسال تذكرة التحويل مباشرة إلى مجموعة تيليجرام خاصة بفريق الدعم (`Staff Group`).
  - إمكانية رد الموظف من داخل المجموعة عبر الرد المباشر (**Reply**) على رسالة التنبيه، ليقوم البوت بنقل الرد تلقائياً لمحادثة العميل الخاصة.
  - تعليق الرد الآلي وتمرير رسائل العميل اللاحقة للمجموعة لمنع تداخل الذكاء الاصطناعي مع الموظف.
  - دعم أمر `/resolve` لإنهاء التذكرة، وأمر `/bot` للعميل لاستئناف الرد الآلي في أي وقت.
- 💾 **Persistent Conversation Memory:** ذاكرة محادثة دائمة باستخدام **SQLite**، يتم استرجاع آخر `MEMORY_WINDOW` رسائل لكل عميل بشكل معزول تماماً، مما يضمن استمرارية السياق حتى بعد إعادة تشغيل السيرفر.
- 🛡️ **Medical Safety & Triage:** التزام صارم بعدم التشخيص أو وصف الأدوية، مع نظام توجيه وتصعيد فوري للطوارئ عند رصد أعراض خطيرة (فقدان مفاجئ للرؤية، ألم حاد، إلخ).
- 📅 **Appointment Booking:** حجز المواعيد والخدمات وتسجيلها محلياً في جدول الحجوزات.
- ⚡ **Resilient Network Handling:** معالجة متقدمة لمهل الاتصال (Network Timeouts) وإعادة المحاولة التلقائية لتفادي انقطاعات الشبكة.

## 🏗️ معمارية المشروع (Project Architecture)

تم تصميم المشروع وفق معمارية برمجية نظيفة وقابلة للتوسع (Clean & Modular Architecture):

```text
visioncare-ai/
│
├── ai/
│   ├── gemini.py         # تكامل Gemini 3.6 Flash، إدارة الذاكرة، وربط الأدوات
│   └── prompts.py        # قاعدة المعرفة (Knowledge Base) وتعليمات النظام
│
├── bot/
│   ├── handlers.py       # معالجات رسائل الخاص وردود مجموعة الموظفين
│   └── telegram.py       # إعداد التطبيق وتوجيه مسارات الرسائل
│
├── database/
│   ├── database.py       # جداول SQLite والعمليات وترقية الحقول التلقائية
│   └── memory.py         # واجهة إدارة سجل المحادثات وحالة الجلسات
│
├── services/
│   ├── handoff.py        # الربط التفاعلي بين العميل ومجموعة الدعم
│   └── booking.py        # منطق تسجيل وحفظ المواعيد
│
├── config.example.py     # نموذج توضيحي للمتغيرات والإعدادات
├── main.py               # نقطة الدخول والتشغيل الرئيسية
├── test_sqlite.py        # سكربت فحص واختبار قاعدة البيانات وعزل المستخدمين
├── requirements.txt      # المكتبات المطلوبة
└── README.md
